◆ request_service()

request_service ( )

Requests a session key from the TTP and service access from server.

Sends a service request to the main server, then contacts the TTP to retrieve an encrypted AES session key. The key is decrypted using the client's private RSA key and stored globally for later encrypted communication.

Exceptions
socket.error- network communication failure
json.JSONDecodeError- invalid JSON response

◆ send_message()

send_message ( )

Sends an encrypted message to the server.

Encrypts a user-provided message using a AES session key and sends it securely to the server via TCP.

Exceptions
AttributeError- Raised if GUI elements or session key are not initialized
socket.error- Network communication failure

◆ simulate_auth()

simulate_auth ( )

Simulates client authentication with a Trusted Third Party (TTP).

Generates a client ID and RSA keys and performs a registration handshake with a trusted third party (TTP) over a TCP socket The client ID is encrypted with a TTP public key and sent along with the clients public key.

If successfull service access is enabled in the GUI

Exceptions
socket.error- network communication failure
json.JSONDecodeError- invalid JSON response from TTP

◆ test_forged_certificate()

test_forged_certificate ( )

Sends a deliberately forged certificate to the server.

Creates an invalid version of the client's certificate by modifying its contents and sends it to the server. This function is intended for testing the server's certificate handling mechanisms

Exceptions
socket.error- network communication failure

◆ root

gui.root = tk.Tk()

Initializes and runs the client GUI application.

Creates a Tkinter-based GUI that allows the user to:

  • Authenticate with a Trusted Third Party (TTP) ("Log in with TTP")
  • Request a secure AES session key ("Download AES key")
  • Input and send encrypted messages to a server ("Send message") The GUI remains active via the Tk main event loop.
